## Fonte de verdade

Os arquivos de código e configuração são a referência para detalhes de implementação. Quando a documentação divergir do código, corrija o documento junto com a mudança ou registre a diferença como pendência. Os arquivos em project/archive são registros antigos e não representam o estado atual nem um backlog ativo.
