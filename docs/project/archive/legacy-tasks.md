# Lista antiga de tarefas — arquivo

Este arquivo registra um snapshot histórico de tarefas de entrega e relatórios. As tarefas marcadas como feitas ou pendentes não descrevem necessariamente o estado atual.

A lista mencionava segunda tela manual/automática, sorteio, estorno e reset de entregas, relatórios agrupados, modelo de exportação, relação de entrega e novas informações para retirada por terceiros. Parte desses itens está implementada; limites atuais e formatos estão descritos no [README principal](../../../README.md) e em [entrega de kits](../../frontend/delivery.md).

Não use este arquivo como plano de trabalho atual sem revalidar cada item.
