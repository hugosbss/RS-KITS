# Notas antigas de produto — arquivo

Este resumo substitui as anotações antigas de trabalho. Os itens marcados como feitos eram registros do momento em que foram escritos; confirme o estado no código antes de usá-los.

As notas registravam ajustes no dashboard, na tabela de entrega, na importação de planilhas, em alertas, campos de atleta e filtros de análise. Também listavam, como pendências naquele momento, inclusão de número de inscrição, acesso de organizador, controle de acesso após evento e exibição de faixa etária. Esta lista não deve ser tratada como backlog atual.

A especificação vigente da entrega fica em [docs/frontend/delivery.md](../../frontend/delivery.md).
